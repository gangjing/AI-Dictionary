1[计算机与网络工程]数据传输往返时延（Round-Trip Time）；响应时延

指从发送请求指令到系统接收并开始响应数据包之间的时间间隔。在分布式架构中通常细分为传播时延（propagation）、传输时延（transmission）、排队时延（queuing）与处理时延（processing）。

2[医学与病理学]潜伏期；隐匿潜伏状态（Pathogen Dormancy）

病原体侵入机体至出现最初临床症状之间的间隔时段，或病毒在宿主细胞内处于非活跃休眠期的状态（如带状疱疹病毒或 HIV 潜伏感染）。

3[心理学与认知科学]反应时；刺激至反应间隔（Reaction Latency）

自外界物理刺激作用于感官感受器开始，到受试者产生可测量行为反应之间的极微时间差。
